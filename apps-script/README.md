# 문의 접수 설치 방법

홈페이지 고객문의 폼을 받아서 메일로 보내고 스프레드시트에 기록하는 설정입니다.
한 번만 해두면 됩니다. 10분 정도 걸립니다.

## 1. 스프레드시트 만들기

1. `sheets.new` 주소로 새 구글 스프레드시트를 만듭니다.
2. 이름을 `KJS 문의 접수` 로 바꿉니다.

## 2. 스크립트 붙여넣기

1. 그 스프레드시트에서 **확장 프로그램 → Apps Script** 를 엽니다.
2. 편집기에 있던 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 전부 붙여넣습니다.
3. 저장합니다.

## 3. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 톱니바퀴를 눌러 유형을 **웹 앱** 으로 고릅니다.
3. 설정을 이렇게 맞춥니다.
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. 배포를 누르면 권한 승인 창이 뜹니다. 승인합니다.
   («이 앱은 확인되지 않았습니다» 경고가 나오면 **고급 → 이동** 을 누릅니다.
   본인이 만든 스크립트라 정상입니다.)
5. 배포가 끝나면 **웹 앱 URL** 이 나옵니다. `https://script.google.com/macros/s/..../exec`
   형태입니다. 이 주소를 복사합니다.

## 4. 홈페이지에 주소 넣기

`dist/app.js` 파일 위쪽에 이 줄이 있습니다.

```js
const INQUIRY_ENDPOINT='';
```

따옴표 안에 3번에서 복사한 주소를 넣고 저장한 뒤 `main` 에 반영하면 됩니다.

```js
const INQUIRY_ENDPOINT='https://script.google.com/macros/s/..../exec';
```

주소를 넣기 전까지 폼은 기존처럼 메일 앱을 여는 방식으로 동작합니다.
주소를 넣는 순간부터 서버로 직접 접수됩니다.

## 5. 확인

홈페이지 고객문의 페이지에서 본인 이름으로 한 번 보내보십시오.

- `info@kjs-elec.kr` 로 메일이 와야 합니다.
- 스프레드시트에 `문의접수` 시트가 생기고 한 줄이 쌓여야 합니다.

## 스프레드시트에 비워둔 두 칸

`어떻게 알았나`, `수주 여부` 칸은 자동으로 채워지지 않습니다.
상담하면서 손으로 적으시면 됩니다. 한 달치가 쌓이면
어느 채널에서 문의가 들어오는지, 어디에 광고비를 쓸지 숫자로 보입니다.

## 스팸이 들어오면

폼에는 사람 눈에 안 보이는 칸이 하나 있어서, 자동 프로그램이 거기를 채우면
접수되지 않습니다. 그래도 스팸이 들어오면 알려주십시오.
스크립트에 추가로 막는 조건을 넣겠습니다.
